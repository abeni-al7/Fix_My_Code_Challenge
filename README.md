# Fix My Code Challenge

Debugging exercises from the ALX Africa Software Engineering programme. Each challenge ships with code that contains bugs; the task is to fix it so it behaves as specified, without rewriting it from scratch.

## Contents

- `0x00-challenge/` — challenge 0, including `0-fizzbuzz.py`, a command-line FizzBuzz that prints numbers `1..n` with multiples of 3 as `Fizz`, 5 as `Buzz`, and both as `FizzBuzz`.

## Built with

- Python 3

## Run it

```bash
./0x00-challenge/0-fizzbuzz.py 89
```

Educational debugging coursework.
